### ADR-001：保留媒体原始时基并统一为微秒

选择以视频轨道起始时刻为原课零点；音轨使用相同零点，保留二者起始偏移，不能将两个轨道分别归零。seek 先回到关键帧再向前解码，记录第一张不早于请求的实际帧 PTS。

原因：独立缓存音视频和片段转写都需要准确回到原课。仅保存请求秒数无法证明抽到的画面时刻。PyAV 官方 [seek 文档](https://pyav.org/docs/stable/api/container.html) 明确说明偏移使用 stream time base，seek 后仍需向前解码。

### ADR-002：只读偏移视图适配缓存前缀

仅在确切九个 ASCII `0` 和随后合法 ISO BMFF 首 box 同时成立时启用偏移，不按 `.m4s` 扩展名删头。不生成整课媒体副本，不读整课到内存。普通视频也使用同一只读封装与轨道探测。

原因：保留源文件、限制内存，且避免把损坏文件或其他客户端格式误判成已知缓存。

### ADR-003：按固定音频窗口识别并保存重叠区所有权

每次 120 秒、两侧最多 2 秒上下文；重采样结果按 PTS 放回 16 kHz mono 缓冲，静音和时间空隙保留。ASR 使用 faster-whisper 自带 VAD 时间还原；输出句段按中点分配到窗口所有权范围，再裁到合法边界，保留原始识别边界。

原因：整课内存不随时长增长；重叠提供句边界上下文，归属规则避免相邻窗口重复段落。跨窗口的识别文本不承诺逐字精确去重，真实边界仍需核对。

### ADR-004：OS 文件锁与临时目录发布

Windows 使用 msvcrt 字节锁，其他平台采用 flock。锁文件保留，持有者异常退出由 OS 释放锁，不根据年龄删除文件。新转换在相邻临时目录生成和校验，最后 rename 发布；失败目录记录失败状态，不登记成功版本。

原因：仅使用“锁文件存在”无法可靠处理崩溃；关闭后立刻删除锁文件存在竞争。临时目录发布让使用者不会读到半写入的成功版本。

### ADR-006：禁用默认思考并禁止相同参数的截断重试

默认 reasoning_effort=none，将输出预算用于忠实整理；用户可配置推理强度。网络瞬时故障、结构或引用错误仍有界重试；输出截断没有理由按相同 token 上限重复请求，直接报告未完成。SDK 的自动重试关闭，计数覆盖每次真实请求。

原因：首轮服务成功返回但因 token 上限截断，重复相同请求会继续消耗费用。此选择影响延迟和推理深度，不能据此推断数学内容必然准确；真实内容仍要核对。提示版本 p0-2 另明确 LaTeX 和代码围栏格式，先前运行日志保留实际 p0-1，不改写历史记录。

### ADR-007：周期候选弥补小面积板书变化

全局灰度均差容易忽略逐笔书写：真实数学 10 分钟最初只留下 4 张章节起点候选。现在在固定采样网格上至少每 30 秒保留候选，再由模型去掉近似重复插图，10 分钟保留 20 张图。新增自造小面积临时符号测试覆盖这一风险。

原因：仅将全局阈值调得极低会把人物移动也当成关键变化；周期候选提供中间状态覆盖，又不引入 P1 自动布局或自主补帧。快速出现又消失的内容仍可能遗漏，允许用户精确换图。

### ADR-008：当前文稿是修订基线，模型只获得受限范围

修订先校验快照、结构化索引、源文件指纹和提取参数，再提供当前目标字节对应的文本。最终只拼接前缀、替换片段、后缀，发布前复查当前文件哈希。保留的手改块及整份文稿的结构化同步状态显式标为未核验；安全相对图片一起复制。

图注文字修订仅向模型提供当前图片，避免文字操作暗中换图；按时间的图像操作不调用模型。原图注保留，加入图文一致性疑点。

原因：重新渲染整篇会丢手改和换行，隐式“最新版”会让修订基线不可预测。锚点或受控图片/来源行冲突时，诊断与建议片段比猜测替换范围可靠。

### ADR-009：本地快速模式独立于标准模式

同一组 60 秒音频比较候选数、线程和批次。单纯减少搜索或增加到 8 线程并非每段更快；4 线程、batch=4、单候选分别从 51.0/27.8 秒降至 16.9/15.5 秒。添加可选 fast，标准模式保持兼容。批次显式开启时间戳，保留 VAD 还原；不因加速改写时间。术语文本有差异，不声称同等准确率。

### ADR-012：Qwen 3.8 Flash 图文适配与流式边界

用户指定阿里云 Chat Completions、qwen3.8-flash、enable_thinking=true 和 stream=true，因此新增 Qwen 图文适配器，与 DeepSeek 共用有界请求、Draft 校验和证据约束。没有创建插件框架，也未请求 OpenAI 服务。ASR 仍是独立的 Qwen 云端路径。

流中的 reasoning_content 只触发阶段提示，不记录原始思考；delta.content 拼为最终 JSON。仅正常停止且正文非空才接受，usage 空 choices 尾块单独收集。异常关闭流、丢弃部分正文，重试计入同一调用预算。预算默认 1024，输出上限沿用 6000，可配置。
